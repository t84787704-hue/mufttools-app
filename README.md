

# MuftTools - All-in-One Utility Android App

MuftTools is a fast, privacy-focused, offline-capable utility app built with Kotlin and Jetpack Compose.

## Key Features
- 📷 **Image Tools**: Professional interactive crop editor (pinch-to-zoom, pan, handles, aspect ratios, rule-of-thirds grid), high-quality resizing, compression, rotation, and format conversion.
- 📄 **PDF Scanner**: Scan documents, crop pages, reorder, apply filters, and export high-quality PDFs.
- 🔍 **QR & Barcode Tools**: Fast camera scanner, history tracking, and custom QR code generator with batch export.
- 🎬 **Video Compressor**: Efficient video compression with custom quality presets.
- 🎨 **Light & Dark Theme**: Dynamic Compose theme supporting Light Mode, Dark Mode, and System Default.
- 📳 **Haptic Feedback**: Tactile vibration feedback on button clicks and tool completions.

## Build Requirements
- Android SDK 34+
- Kotlin 2.0+
- Jetpack Compose with Material Design 3
